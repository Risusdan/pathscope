# Data Path Explorer UI (M3-M4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the approved PySide6 prototype onto the real M0-M2 engine:
live spec-book diagram, register inspector, flow panel, event log, memory
viewer, plus the four core-hardening items parked at the M0-M2 final
review.

**Architecture:** `core/` grows four hardening features (guarded-register
overlay, merge-splitting read plan, locked history, dynamic watch set) and
stays Qt-free. A thin `ui/` package consumes `EngineUpdate` via a
QObject bridge (cross-thread signal emission gives queued delivery on the
Qt main thread). Diagram visuals are ported class-by-class from
`prototype/ui_proto.py` (the approved visual reference, present in-repo)
with exact deltas listed per task; the prototype file itself is never
modified. A `--demo` mode drives the whole UI from a MockAdapter so the
app runs and screenshots without hardware.

**Tech Stack:** Python 3.9, PySide6 >= 6.5 (new `ui` extra), pytest,
pytest-qt (new dev dep), existing core (pyocd, PyYAML).

**Spec:** `docs/superpowers/specs/2026-09-12-data-path-explorer-design.md`
(sections 6.2, 6.3, 7 govern; section 7 was validated via the prototype).

## Global Constraints

- Python 3.9 compatible syntax only (typing.Optional/List/Dict/Set/Tuple;
  no `match`, no `X | Y` unions).
- `core/` must never import Qt or anything from `ui/`.
- Pure ASCII in all source files.
- Light theme only, permanently: `app.styleHints().setColorScheme(Qt.ColorScheme.Light)`
  wrapped in try/except AttributeError. Never follow the OS appearance.
- `EngineUpdate.badges` is a sparse dict: ALWAYS access with `.get()`.
- Engine callbacks fire on the poller thread; UI code touches widgets only
  on the Qt main thread (the bridge's queued signals guarantee this; never
  bypass the bridge).
- All hardware access from UI goes through `Engine` methods (which route
  через the poller command queue) - never touch the adapter directly.
- Visual constants come from the prototype: kind tints (peripheral #E9F3E7,
  dma #E4EDF7, memory #FBF3DC, cpu #ECECEC, interconnect #F1EAF3), active
  blue #1565C0, selection orange #E65100, anomaly red #C62828, mux-off grey
  #B0B0B0, flash yellow #FFF59D, white canvas, monospace values.
- Tint mode defaults ON; legend always present; toolbar buttons 14px text
  with generous padding (QToolButton padding 7px 16px).
- Commit after every task, Conventional Commits.
- Run everything from repo root; python/pytest via `.venv/bin/`.
- UI tests run offscreen: they must set `QT_QPA_PLATFORM=offscreen` (a
  conftest fixture does this) and must pass with no display and no
  hardware.
- Hardware-gated steps are marked; the controller runs them with the user.

```python
def build_read_plan(reg_keys: Set[str], model: RegisterModel,
                    merge_gap_words: int = 8,
                    forbidden_addrs: FrozenSet[int] = frozenset()
                    ) -> List[ReadOp]:
    entries = sorted((model.resolve(k).address, k) for k in reg_keys)
    forbidden = sorted(forbidden_addrs)
    plan: List[ReadOp] = []
    for addr, key in entries:
        if addr in forbidden_addrs:
            # guarded target: isolated single-word op, never merged
            plan.append(ReadOp(addr=addr, count=1, targets=[(key, 0)]))
            continue
        if plan:
            cur = plan[-1]
            cur_end = cur.addr + 4 * cur.count
            gap = (addr - cur_end) // 4
            spans_forbidden = any(cur_end <= f < addr for f in forbidden)
            merged_would_span = any(cur.addr <= f <= addr
                                    for f in forbidden)
            if (0 <= gap <= merge_gap_words and not spans_forbidden
                    and not merged_would_span
                    and cur.addr not in forbidden_addrs):
                cur.count = (addr - cur.addr) // 4 + 1
                cur.targets.append((key, (addr - cur.addr) // 4))
                continue
        plan.append(ReadOp(addr=addr, count=1, targets=[(key, 0)]))
    return plan
```

```python
    def set_watch(self, extra: Set[str]) -> List[str]:
        refused = []
        accepted = set()
        for key in extra:
            rr = self.model.resolve(key)
            is_guarded = rr.read_action is not None \
                or key in set(self.flowspec.guarded)
            if is_guarded and key not in self.flowspec.force_poll:
                refused.append(key)
            else:
                accepted.add(key)
        self._extra = accepted
        self.polled = set(self._base_polled) | accepted
        plan = build_read_plan(self.polled, self.model,
                               forbidden_addrs=frozenset(self._guarded_addrs))
        poller = self._poller

        def swap(_adapter):
            poller.plan = plan
        self._poller.submit(swap)
        return sorted(refused)

    def read_words(self, addr: int, count: int,
                   timeout_s: float = 2.0) -> List[int]:
        q = self._poller.submit(lambda ad: ad.read_block32(addr, count))
        try:
            ok, result = q.get(timeout=timeout_s)
        except queue.Empty:
            raise EngineError("read timed out")
        if not ok:
            raise EngineError("read failed: %r" % (result,))
        return result

    def halt(self) -> None:
        self._exec(lambda ad: ad.halt())

    def resume(self) -> None:
        self._exec(lambda ad: ad.resume())

    def _exec(self, fn, timeout_s: float = 2.0):
        q = self._poller.submit(fn)
        try:
            ok, result = q.get(timeout=timeout_s)
        except queue.Empty:
            raise EngineError("command timed out")
        if not ok:
            raise EngineError("command failed: %r" % (result,))
        return result
```

```python
# ui/bridge.py
"""The single crossing point between the engine's poller thread and the
Qt main thread. Signals emitted from a non-Qt thread are delivered as
queued connections - UI slots always run on the main thread."""
from PySide6.QtCore import QObject, Signal

from core.engine.core import Engine


class EngineBridge(QObject):
    update = Signal(object)   # EngineUpdate
    state = Signal(str)

    def __init__(self, engine: Engine, parent=None):
        super().__init__(parent)
        self.engine = engine
        engine.on_update(self.update.emit)
        engine.on_state(self.state.emit)
```

```python
# ui/demo.py
"""Demo mode: a MockAdapter animated by a background thread so the full
UI runs, and anomalies fire, with no hardware attached."""
import threading
import time

from core.adapter.mock import MockAdapter
from core.engine.core import Engine

S0CR = 0x40026410
S0NDTR = 0x40026414
ADC_SR = 0x40012000


def make_demo_engine(target_dir: str = "targets/f411") -> Engine:
    mem = {S0CR: 1, S0NDTR: 1000, ADC_SR: 0x10}
    adapter = MockAdapter(mem)
    engine = Engine.load(target_dir, adapter, interval_s=0.03)

    def animate():
        t0 = time.monotonic()
        while True:
            elapsed = time.monotonic() - t0
            phase = elapsed % 12.0
            if phase < 9.0:                       # normal streaming
                ndtr = adapter.mem.get(S0NDTR, 1000) - 37
                adapter.set_word(S0NDTR, ndtr if ndtr > 0 else 1000)
                adapter.set_word(ADC_SR, 0x10)
            elif phase < 11.0:                    # fault window
                adapter.set_word(ADC_SR, 0x30)    # OVR set
            else:                                 # recover
                adapter.set_word(ADC_SR, 0x10)
                adapter.set_word(S0NDTR, 1000)
            time.sleep(0.05)

    threading.Thread(target=animate, daemon=True).start()
    return engine
```

(Note: the fault window freezes NDTR by simply not decrementing it, so
`stalled()` fires ~500 ms in, and OVR fires immediately - matching the
real firmware's behavior shape.)
